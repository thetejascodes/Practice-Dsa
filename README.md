## 📖 About

This repository is my learning log for data structures and algorithms. I follow [Striver's A2Z DSA Sheet](https://takeuforward.org/prep-hub/strivers-a2z-dsa-sheet), and every problem I finish gets its own folder with the C++ solution and a short write-up in my own words: the idea, the approach, and the time and space complexity.

The point is understanding, not a solved-count. If I can't explain a solution without looking at it, it isn't done.

## 🔁 Practice workflow

For each problem, I:

1. **Understand** the problem and the pattern behind it.
2. **Work out the approach** on paper before writing any code.
3. **Implement and test** the solution, including edge cases.
4. **Analyze** time and space complexity.
5. **Explain** the solution in my own words in the problem's README.

A problem only gets ticked off once step 5 is written.

## 📝 Notes template

Each problem's README follows the same shape, so every write-up is easy to scan and revise later.

````markdown
# <Problem name>

**Section:** <e.g. Patterns> · **Difficulty:** <Basic / Core / Pro>

## Problem
<what is being asked, with a small example>

## Approach
<the idea in plain words, plus how I got there>

## Solution
<C++ code, or a link to solution.cpp>

## Complexity
- Time: O(...)
- Space: O(...)

## Edge cases
<what could break it>

## What I learned
<one thing to remember next time>
````

## 📐 Complexity cheat sheet

Quick reference I come back to while analyzing solutions.

| Growth | Name | Typical example |
| --- | --- | --- |
| O(1) | Constant | Array index, hash lookup |
| O(log n) | Logarithmic | Binary search |
| O(n) | Linear | One pass over an array |
| O(n log n) | Linearithmic | Merge sort, sorting with `std::sort` |
| O(n²) | Quadratic | Nested loops, most pattern problems |
| O(2ⁿ) | Exponential | Subsets by recursion |
| O(n!) | Factorial | Permutations by brute force |

**Rough limits** (about 10⁸ simple operations per second):

| n up to | Aim for |
| --- | --- |
| 10⁸ | O(n) or better |
| 10⁶ | O(n log n) |
| 10⁴ | O(n²) |
| 20–25 | O(2ⁿ) |
| 10 | O(n!) |
